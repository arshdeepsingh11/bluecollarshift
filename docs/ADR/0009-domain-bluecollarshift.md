# ADR 0009 — Domain bluecollarshift.com
Status: accepted (2026-11-25)
**Context:** Brand is Blue Collar. `bluecollar.com` and most close variants were taken. A typo domain (bluecollor.com) was bought and refunded.
**Decision:** `bluecollarshift.com` (registered at Vercel). Hosts: `bluecollarshift.com` (public), `app.` (employers/employees), `admin.` (platform), `api.` (API). Replaces hafs-s.com.
**Also:** mobile bundle id / Android package changed to `com.bluecollarshift.app` before any store release (permanent after release).
